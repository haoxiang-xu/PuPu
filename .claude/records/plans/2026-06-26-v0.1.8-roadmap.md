## P0 · 本版核心交付

### A. MCP 本地运行时补齐到 Windows/Linux 🔴 CEO 指定优先级
> 让用户装的 MCP server 在三平台都真能跑,不依赖用户自己装 uv/node。

- **方案**:走**路线 B(补齐已有下载式)**,不走字面"打包进安装包"(后者体积翻倍 + mac 公证地狱 + 还不真离线)。
- **改造点**(`unchain_runtime/server/mcp_managed_runtime.py`,**归属 `pupu-dev-backend`**):
  - [ ] `resolve_managed_stdio_runtime` 去掉 `sys.platform != "darwin"` 的早返回(L416-417)
  - [ ] `_install_node_runtime`:加 win(`.zip` / `npx.cmd` 在根目录)、linux(`.tar.xz`)分支;现硬编码 darwin/`osx-{arch}-tar`/`tar.gz`/`bin/npx`
  - [ ] `_install_uv_runtime`:加 win(`uv-x86_64-pc-windows-msvc.zip`)、linux(`uv-{arch}-unknown-linux-gnu.tar.gz`)
  - [ ] `_safe_extract`:支持 `xz` 与 `zip`(现仅 `r:gz`)
  - [ ] `tests/test_mcp_managed_runtime.py`:补三平台用例
- **体量**:中。无新 IPC、无前端改动、无打包配置改动。
- **风险/交接**:若将来要"离线预置二进制进安装包"(路线 C),才动 `package.json` extraResources + mac 签名公证 → **接近单向门,必须先开 CTO 同步会**(roster:cto + dev-backend + security-expert + mcp-store-curator)。0.1.8 不碰 C。
- **参考**:Electron dev 完整调查报告(task `a649e25fc09961874` 产出)。

### B. 记忆「通电」🔴 差异化锚点
> 0.1.8 后端已建好整套记忆 CRUD,但没接线。把它接通就是本版最实在的差异化交付。

- [ ] **后端注册路由**:在 app 启动处调 `register_memory_routes`,让 11 个 `/memory/*` 路由真正可访问(现为死代码)。归属 `pupu-dev-backend`。
- [ ] **前端接管理界面**:`list + delete` 最小闭环,让用户**看得到 / 删得掉**记忆。归属 `pupu-dev-settings`(memory-inspect / settings/memory)。
- [ ] **手头改动着陆**:`memory_factory.py +124` 等未提交改动 → 提交、补测试、跑绿。
- ⚠️ **受 D1 单向门约束**:在场信号必须走 `flow_event.v1` append-only 信封,**禁止 UI 直查 Qdrant**。此契约需 `pupu-architect` 先定案(见 P1)。

### C. 记忆质量基线(recall eval)🔴 差异化
- [ ] 搭 30–50 条 recall 测试集,跑出基线数。归属 `pupu-llm-expert`。
- [ ] 顺序:**先量化基线(0.1.8)→ 再调参(0.1.9)→ 达标才对外(0.2.0 硬门 D4)**。

## P1 · 地基(本版应做)

### D. onboarding 骨架
- [ ] 空状态 / 可跳过配 key / 人话失败态。**UI 可简陋但不能丑**(首启动是唯一第一印象)。归属 `pupu-ux-designer` + `pupu-dev-settings`。
- [ ] Gemini settings UI **补齐**(文档宣称支持但 UI 缺失;补,不删——免费长上下文对 onboarding 有用)。

### E. 记忆事件契约定案(D1 单向门)⚠️
- [ ] `pupu-architect` 给「记忆即在场感」定 `flow_event.v1` 信封落位契约——只定接口/形态,不写功能码,确保不和未来 always-on 打架。**这是唯一"早决定省大钱"的卡点,B 的前置。**

### F. CI 装锁
- [ ] `release-qa.yml` 加 `push` 触发 + 开 main/dev branch protection,让 229 个测试变成真门禁。归属 `pupu-coo`,dev-electron 顾问。工作量 1–2h。
- [ ] 前端 5 套件修绿 + CI 产出 Win/Linux 构建产物并跑一次冒烟。

### G. 安全过审补一轮 ⚠️
- [ ] 规划会上 security-expert 缺席。0.1.8 涉及**遥测埋点 + 记忆持久化写边界 + 下载式二进制供应链**,需 `pupu-security-expert` 单独过审(换可用模型)。不阻塞路线图,首发前必做。
