# PuPu 决策记录索引

> 这里存放 PuPu 的**会议记录**与**行动计划**。每开一次会、定一个版本计划,就在对应目录加一份,并在此登记一行。

## 目录约定

```
.claude/records/
  INDEX.md          ← 本文件,所有文档的索引(新增文档必登记)
  meetings/         ← 会议记录(讨论、决策、共识)
  plans/            ← 行动计划(版本路线图、待办、归属)
```

**命名规范**:`YYYY-MM-DD-<短标题>.md`(日期用绝对日期,便于排序与回溯)。
**配对惯例**:一场规划会通常配一份 plan;会议记录负责"为什么这么定",plan 负责"具体做什么"。两者互相链接。
