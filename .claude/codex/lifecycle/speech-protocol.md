# 庭审发言协议

[Quorum 索引](../README.md) · [Case Lifecycle](README.md)

发言标准约束的是一条发言 **如何进入案卷及如何被回应**，不是要求所有角色使用相同的论述方式。每条发言由一层所有角色共用的 **公共信封**，加一层由发言动作或角色决定的 **类型载荷** 组成。

## 公共信封

每条进入案卷的发言都必须使用以下结构，五个字段不得省略；没有内容时填写 `无`，不得以留空表示:

```markdown
#### S-0001 | CLAIM | expert-security → case
- **阶段**: 议案庭审
- **结论**: ...
- **依据**: E-0001, S-0000
- **不确定性**: ...
- **请求/下一步**: ...
- **主张类型**: FACT
```

- `S-####` 是 case 内按归档顺序单调递增的 **发言编号**，一经分配不可修改或复用
- **一条发言，一个主动作，一个可独立回应的核心结论**；相互无依赖的主张必须拆分，支撑同一结论的多项证据可以合并引用
- `speaker` 必须使用角色 instance 的正式名称；`target` 必须是 `case`，某个 `S-####`，`E-####`，`R-####`，方案编号，或被传唤角色
- 回答，反对，修正与撤回必须引用其直接 target；不得用“上面提到的”“之前那个方案”等位置性表述
- 已归档发言不得原地改写。内容有误时，以新的 `WITHDRAWAL` 撤回，再提交替代发言；旧记录保留但标注失效
- **依据** 只接受可追溯的 `E-####`，`S-####`，`R-####`，方案编号或法典条目；`无` 表示发言不主张证明力，不得把未编号的背景叙述当作证据
- **不确定性** 必须写明未知前提，适用边界或可能改变结论的条件；确认不存在时填写 `无`

## 发言动作

| 动作 | 用途 | 类型载荷与约束 |
|---|---|---|
| `FRAMING` | `Speaker of the House` 框定本次庭审 | 登记待裁问题，范围，已知事实，已知缺口及必到角色与交付 |
| `NOTICE` | 发布开庭，休庭，恢复，闭庭或其他程序通知 | 标注通知类型，生效时间及影响范围；不承载实体立场 |
| `CLAIM` | 提出待证明的事实或推论 | 标注 `FACT` 或 `INFERENCE`；`FACT` 引用直接证据，`INFERENCE` 引用完整推导所依赖的证据或发言 |
| `EVIDENCE` | 将候选证据提交证据台账 | 在发言中登记证据编号，正文位置及支持或反驳的 target；来源与完整性元数据只写入 `evidence.md` |
| `QUESTION` | 向一个明确对象提出一个可直接回答的问题 | 给出问题，回答对象及其对当前争点的影响；不得把观点或多项问题包装成问句 |
| `ANSWER` | 回应一个 `QUESTION` | 引用问题编号，标注 `ANSWERED`，`UNKNOWN` 或 `UNCERTAIN`；只回答所问范围，额外主张另开 `CLAIM` |
| `OBJECTION` | 对发言，证据或方案提出可处理的异议 | 引用 target，并标注 `UNSUPPORTED`，`SOURCE`，`RELEVANCE`，`CONTRADICTION`，`SCOPE` 或 `PROCEDURE`；说明若异议成立会改变什么。**target 为 `E-####` 且类型为 `SOURCE` 或 `UNSUPPORTED` 的，构成[宪法第五条](../constitution.md)的质疑**：满足形式要件即 **强制触发 `Evidence Examiner` 审查**，`Speaker of the House` 无裁量权拒绝；补强该证据的责任归于提出者，异议方不承担证明其为假的责任 (见[证据规则](evidence-rules.md)) |
| `PROPOSAL` | 提交可供裁定的方案 | 在发言中登记方案编号与目标结果；完整方案归档于 `proposal.md`，写明实施范围，关键步骤，风险，可逆性与回滚或补救方式，以及可验收标准；不同结果的方案不得混写 |
| `AMENDMENT` | 对既有方案提出局部修正 | 引用方案及 `proposal.md` 中的修正块，登记变更摘要，理由及风险影响；改变目标结果或验收标准时必须另立 `PROPOSAL` |
| `ASSESSMENT` | 提交角色职责要求的正式意见 | 使用下述角色输出契约；不得以通用评论代替角色必须给出的结论 |
| `SUMMONS` | 签发符合门禁的传票 | `Witness` 传票须包含单一问题，受影响事项，已查来源，本人知情理由与 blocking 状态 |
| `TESTIMONY` | `Witness` 回应传票 | 引用 `SUMMONS`，标注 `KNOWN`，`UNKNOWN` 或 `UNCERTAIN`，分配证据编号，并给出知识来源，答案边界及可佐证线索 |
| `SIDE_CASE_MOTION` | 动议开立 side case | 登记超出范围的问题，超出范围依据，与 parent case 的关系及支撑证据 |
| `WITHDRAWAL` | 撤回已经归档的发言 | 引用被撤回编号，说明原因及替代发言编号；不得借撤回删除历史记录 |
| `SUMMARY` | `Speaker of the House` 提交闭庭忠实汇总 | 分列共识，分歧，已知缺口，候选方案，风险，强制回应事项及未答 non-blocking 传票 |

公共信封之后，必须按下列顺序追加对应动作的固定字段；字段不得改名或换序，不适用时填写 `无`:

- `FRAMING`: **待裁问题**，**范围**，**已知事实**，**已知缺口**，**必到角色与交付**
- `NOTICE`: **通知类型** (`OPENING / RECESS / RESUMPTION / CLOSURE / PROCEDURAL`)，**生效时间**，**影响范围**
- `CLAIM`: **主张类型** (`FACT / INFERENCE`)
- `EVIDENCE`: **证据编号**，**正文位置**，**支持/反驳**
- `QUESTION`: **问题**，**回答对象**，**重要性** (`MATERIAL / NON_MATERIAL`)，**受影响事项**
- `ANSWER`: **问题编号**，**回答状态** (`ANSWERED / UNKNOWN / UNCERTAIN`)
- `OBJECTION`: **异议编号目标**，**异议类型** (`UNSUPPORTED / SOURCE / RELEVANCE / CONTRADICTION / SCOPE / PROCEDURE`)，**受影响事项**
- `PROPOSAL`: **方案编号**，**正文位置**，**目标结果**
- `AMENDMENT`: **目标方案**，**修正块**，**影响字段** (`IMPLEMENTATION_SCOPE / STEPS / RISK / REVERSIBILITY / REMEDIATION`)
- `ASSESSMENT`: **评估结论**，然后按角色输出契约追加字段
- `SUMMONS`: **问题**，**受影响事项**，**已查来源**，**本人知情理由**，**阻塞状态** (`blocking / non-blocking`)
- `TESTIMONY`: **回答状态** (`KNOWN / UNKNOWN / UNCERTAIN`)，**证据编号**，**答案**，**知识来源**，**适用边界**，**可佐证线索**
- `SIDE_CASE_MOTION`: **side case 标题**，**问题**，**超出当前范围依据**，**关系** (`blocking / non-blocking`)，**支撑证据**
- `WITHDRAWAL`: **撤回编号**，**撤回原因**，**替代编号**
- `SUMMARY`: **共识**，**分歧**，**已知缺口**，**候选方案**，**风险**，**强制回应事项**，**未答 non-blocking 传票**

纯粹的“同意”“赞同”或对既有内容的改写不形成新发言。需要表明一致时，在本角色有义务提交的 `ASSESSMENT` 中引用既有编号，并只补充本角色独有的测量，影响或条件。

## 角色输出契约

`ASSESSMENT` 在 **评估结论** 之后，必须按以下顺序追加职责特有字段:

- `Code Owner`，`Task Owner`，`Knowledge Owner`: **边界命中依据**，**受影响对象**，**约束**，以及职责范围内的 **建议处置**
- `POV Owner`: **既定立场**，**与议案的冲突点**，**支持证据**，以及在该观点下可接受的 **条件**
- `Codex`: **法典条目编号**，**当前置信度**，**修订状态**，以及该条目与当前争点的关系
- `Expert`: **评估结论** 只允许 **成立 / 不成立 / 有条件成立**，随后为 **专业适用范围**，**专业理由**，**支撑证据**；有条件成立时在 **不确定性** 中列出全部必要条件
- `Dimension Owner`: **评估结论** 只允许 **支持 / 反对 / 弃权**，随后为 **测量方法**，**测量结果**，**方向性声明**；无法测量必须直接写明，不得用估计代替
- `Evidence Examiner`: **评估结论** 依 **来源类型** 使用不同枚举，随后为 **证据编号**，**来源类型** (`general / human-testimony`)，**真实性**，**可靠性**，**相关性**，**来源归类**。`general` 只允许 **已验证 / 未验证 / 相矛盾**；`human-testimony` 只允许 **已佐证 / 未佐证 / 相矛盾**
- `Acceptance Inspector`: **评估结论** 只允许 **通过 / 不通过**，随后为 **验收标准引用**，**检查方法**，**观察结果**
- `Witness`: 只使用 `TESTIMONY`，提交 **回答状态**，**证据编号**，**答案**，**知识来源**，**适用边界** 与 **可佐证线索**；不得在证言内作方案取舍
- `Procedural Judge` 不使用 `ASSESSMENT` 提交裁定；裁定正文进入 `ruling.md`，`Speaker of the House` 只以 `NOTICE` 引用该记录
- `Speaker of the House` 只使用 `FRAMING`，`NOTICE`，`SUMMONS` 与 `SUMMARY`，不提交实体立场

## 发言流程

每次议案庭审，方案庭审或验收庭审依次经过以下五个发言阶段:

1. **议题框定**: `Speaker of the House` 以 `FRAMING` 归档本次庭审需要回答的待裁问题，范围，当前已知事实，已知缺口，必到名单及每个必到角色应交付的角色输出
2. **独立首轮提交**: 必到角色按各自输出契约独立发言；可并行提交，不要求先阅读其他角色的结论。`Witness` 不参加例行首轮，仅按传票出庭
3. **定向质询**: 以 `QUESTION`，`ANSWER`，`EVIDENCE` 与 `OBJECTION` 围绕具体编号展开。一个线程只有在出现新证据，实质更正或尚未直接回答的问题时才继续；重复立场由 `Speaker of the House` 截止并标为未解决分歧
4. **方案形成**: 有实施需要时，由负有方案职责的角色提交 `PROPOSAL`，其他角色以 `AMENDMENT` 或 `OBJECTION` 回应。`Speaker of the House` 可合并相同结果的索引，不得合并或改写不同理由
5. **闭庭检查**: `Speaker of the House` 执行下述门禁；通过后以 `SUMMARY` 形成忠实的裁定材料，不替 `Chief Judge` 推荐批准或驳回

发言平等是指每个出庭 agent 都可依本协议提交证据，质询和异议，不因角色或立场被拒绝；它不等于轮流发言，相同篇幅，或允许重复占用庭审。格式不合规的发言须退回原 speaker 重排，`Speaker of the House` 不得自行改写后代为提交，也不得以格式问题压制其内容。

## 闭庭门禁

宣布闭庭前，`Speaker of the House` 必须逐项确认:

1. 必到角色均已提交职责要求的输出；缺席或弃权已有明确记录
2. 每项具证明力的事实主张都有证据编号，每项证据都有验证状态
3. 每个 material `QUESTION` 已获得 `ANSWERED`，`UNKNOWN` 或 `UNCERTAIN` 回答，或者被列为带影响说明的 **已知缺口**
4. 所有 blocking `Witness` 传票均已回应；non-blocking 未答传票已进入待答清单
5. 所有 `Witness` 传票的 blocking 性质争议均已有 `Procedural Judge` 裁定；争议中的传票不得进入 non-blocking 待答清单
6. 每项 `OBJECTION` 已标记为 **已回答**，**已采纳**，**已撤回** 或 **未解决**
7. 可供裁定的方案彼此可区分，且各自带有风险，可逆性与回滚或补救方式，以及带编号的可验收标准
8. `Expert` 的 **不成立** 与 `Dimension Owner` 的 **反对** 已进入 `Chief Judge` 的强制回应清单
9. 每一条 **被质疑** 的证据均有 `Evidence Examiner` 的审查结论；未获结论的不得进入证明力评估
10. 每一条 **须查类** 与 **证言类** 证据均有 `Evidence Examiner` 的审查结论 (分类见[证据规则](evidence-rules.md))
11. **承重证据复核已完成** —— `SUMMARY` 在 **分歧**、**强制回应事项**、**候选方案**、**风险** 四项中点名的发言，其 `依据` 列出的全部 `E-####` 均已复核，**自证类不豁免**；复核为未验证或相矛盾的，受影响项已重排，且复核结果已显式列入闭庭产出

闭庭产出必须分别列出 **共识**，**分歧**，**已知缺口**，**候选方案**，**风险** 与 **强制回应事项**，并引用原始编号。摘要不是新的证据，也不得取代完整发言记录。
