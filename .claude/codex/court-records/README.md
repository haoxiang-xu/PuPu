# Court Records 庭审档案

[Quorum 索引](../README.md)

庭审程序档案统一存放在 `.claude/court/`，不进入 `.claude/archive/`。文档采用 **YAML frontmatter + 固定 Markdown 字段**: frontmatter 保存可机器读取的状态，Markdown 保存供人阅读的正文；字段名称与枚举值是协议的一部分，不得自行换用同义词。

本页引言与下列子文档共同构成 Court Records 的规范性正文；下列索引仅用于导航，不新增或复述规则。
