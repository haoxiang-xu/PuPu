# `Witness`

[Quorum 索引](../README.md) · [Roles](README.md)

## 角色规则

- human 角色，非 agent，当前与 `Chief Judge` 由同一人担任；两种身份的发言效力严格分离
- 全 team 唯一，不可被多次创建，不可存在多个 instance
- 只在收到符合门禁的 `Witness` 传票后出庭；不进入 agent 候选与审批名单，不承担持续旁听义务
- 仅提供本人直接掌握的事实，不拥有裁决权，方案设计责任或为答案补做调查的义务
- 命名规则: `witness`

## 角色职责

- 传票回应:
    - 对传票中的单一问题选择 **知道**，**不知道** 或 **不确定**
    - 回答 **知道** 时，陈述答案，知识来源及适用边界；回答 **不确定** 时，同时陈述确定部分与不确定部分
    - 回答 **不知道** 或 **不确定** 是有效回答；不得猜测，不得为了推动庭审而补造记忆

- 证言效力:
    - 每次回答分配独立的 `E-####`，作为 **证言证据** 进入证据记录并接受当前获准参与者质证
    - 本人是证言的来源，不等于证言已经外部验证；证言只有成为决策关键证据且被 16% 随机抽中，或经 `Chief Judge` 点名续查时，才由 `Evidence Examiner` 核验。未抽中状态与限制须保留
    - 证言只回答事实问题；涉及偏好，取舍，授权或裁定的问题，须结束作证并以 `Chief Judge` 身份另行处理

- memory 记录记忆责任:
    - 作为 human 角色，记忆由本人自行管理，不受 agent 记录记忆规则的约束
    - `Speaker of the House` 只归档实际证言，不得把未回答内容推断为本人的隐含记忆
