2026-07-20 应 CEO 全方位战略评估要求,我出具的 AI 技术走向备忘(完整版在当次会话交付给 COO/CEO 合成)。此处只存决策级结论,具体数字/价格/型号勿从这里引用,每次重查。

**Why:** CEO 要判断未来 12-24 个月押什么;四路一手取证(labs app 吸收、MCP/skills、computer use、本地模型/BYOK)+ 我的参照系统研究合成。

**How to apply:** 后续任何"做不做 X 功能"的讨论先对照此判断;若 labs 动作与此预测偏离(尤其本地执行、订阅围栏、MCP Apps),更新本记忆。

## 核心裁决(2026-07 时点)
1. **双向挤压确认**:功能面被 labs 免费/20 刀层吸收(memory/RAG/MCP 连接/skills/voice 已全免费;agent mode 在 20 刀层),经济面被订阅捆绑挤压(Anthropic 2026 年初 OAuth 禁令把第三方客户端圈死在 API key;订阅内 agent 用量低于 API 成本)。功能对齐无防御价值。
2. **结构性可守只剩四样**:①跨 provider 中立(labs 不会聚合对手);②用户拥有的可携带记忆/状态(labs 记忆锁账号,可携带性摧毁其锁定,故结构性不做);③开源可审计+无广告(OpenAI 已在免费层跑广告);④开源权重/本地模型的成本套利路由(labs 不会给对手模型导流)。
3. **MCP/skills 标准化 = 拆护城河的整平器**:MCP 入 Linux Foundation、Agent Skills 成开放标准 45+ 客户端采纳、MCP Apps(沙箱 iframe UI)跨厂商共建。连接层人人都有→价值迁移到策展/安全/确认 UX/状态。PuPu plugins 应兼容 SKILL.md 格式吃生态,别守私有格式。
4. **computer use 本地窗口 12-18 个月且在收窄**:OpenAI 云 VM 路线定死;Anthropic 混合(Cowork 本地→+云);微软把 agent 隔离做进 Windows(Agent Workspace)。OSWorld 已超人类基线→能力不再是瓶颈,信任/同意/审计才是。本地形态的可守部分=跨 provider 的脑+本地信任层,不是"能点屏幕"本身。
5. **客户端品类分叉**:薄包装聊天客户端被消解;"执行环境+状态宿主"被放大(METR 50% 视野 ~12h、还在翻倍→自主时长越长,状态/权限/打扰决策所在地越值钱)。最大威胁是 OS 厂商接管该层,独立客户端活在跨 provider×跨 OS 的缝里。
6. **一句话押注:用户拥有的状态层**——unchain+Qdrant+listeners 建成跨 provider、本地持有的 agent 状态/记忆宿主(伪常驻在场感的工程底座)。与北极星完全对齐。
7. Cowork 使用数据(coding <9%,业务流程 33%)支持 PuPu 的非编码定位。开源权重前沿由中国实验室主导、消费级甜点=20-40B MoE(3-4B active),BYOK 经济故事应靠开源权重端点+本地路由,不靠转售西方旗舰 API。

## 资产映射速记
unchain:编排环 loop 本身商品化,值钱在 provider 中立 harness+确认回路+durable execution 方向 | Qdrant 记忆:升值(所有权+可携带,非检索技术) | computer use 混合:条件升值,窗口有限要快 | plugins/skills:门票非差异化,兼容 SKILL.md | characters:裸人设商品化,重构为带状态 recipe/listener 才有价值 | BYOK:对西方旗舰被挤压,对开源权重/本地是优势。
