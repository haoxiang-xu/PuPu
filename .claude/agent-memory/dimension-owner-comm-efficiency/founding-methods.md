# 沟通效率维度 — 已验证测量法（2026-08-04 org-rebalance 实战）

1. **真实 hop vs 图上 hop**: 组织图声称的层级与真实路径可完全脱节。测法: (a) grep 全部 charter 找该层级/角色被承认的证据（上级自认/下级承认/第三方提及三面）; (b) 全 memory 搜实际发生过的转手记录; (c) 对照路由表。案例: CTO 线三个名义 lead 层——上级自认 3/3、下级承认 0/4、charter 提及 0/23、实际 hop 0 次 ⇒ 层不存在, 图错了。
2. **双向承认引用图**: 对每条边界, 双向 grep 两侧 charter。三种形态: 双向（健康, 全组织当时仅 core↔bubble 与 巡↔analyst 两对）/ 单向（信息损失点: 否决权只写在被否决方章程里, 派权利人时无人知道行使）/ 零向（边界只存在于口头）。
3. **交接协议落盘检测**: 查第三方 memory 里的 handoff 记录（如验与检的边界在 qa 的 team_roster_handoff.md 与 coo 的 handoff_protocol.md 双向落盘 = 边界真实生效）。
4. **重叠歧义**: 两个 charter 认领同一件事（同题例题双答案是最硬形态）或一件事零认领。重叠的成本是"猜错重派"的期望浪费, 不是道德问题。
5. **冗余 vs 矛盾是两种病**: "两人干同一件事"（冗余）与"同一件事两套互斥批准路径"（权责矛盾, 如 B2 签字权三方冲突）取证路径不同, 后者要专门扫批准/签字条款。旧镜头曾因此漏报, 引以为戒。
