const mintTokenForDisposition = useCallback(({ chatId, text, disposition }) => {
  if (disposition !== PLAIN_USER_APPROVED_DISPOSITION) return null;

即：一条带该 disposition 的排队消息，在稍后的**程序化**中继时 **不会再弹窗**。

**（四）由（三）得到本条证据的关键意义**：把绑定从「我批准过的这一条消息」改成「这个字符串值，今后出现在哪里都算批准」，**不是把现有机制放宽一档，而是换了一个 subject**。前者的失效面是一条已知消息；后者的失效面是该值今后的所有出现。这是「按凭据记住」与现状之间的真实差距，不能用"反正已经有持久化了"来抹平。
