## Measured runtime contract (fixed installed pair, before implementation)

Fixed wheel `4e3efdc0…45427b`, manifest `sha256:f6daf389…a28101`. Hand-built candidate documents (labelled as such) went through source `SkeletonResourceStore` save/get/diagnostics/preflight and, for runnable cases, the real public Skeleton chat stream with an offline scripted OpenAI SDK (evidence `native-advanced/branch-351/branch-candidate-capture-01.json`).

- Node envelope CLOSED `{id,type,config}`. `if_else` `config.execution` = `{inputs, condition}`; `switch_case` = `{inputs, value, cases}`. Neither has `outputs`; downstream refs to a branch node are refused (`missing_value`). Branch nodes export nothing.
- Condition AST CLOSED: group `{kind: all|any, conditions: [≥1]}`; comparison `{kind: compare, operator, left, right?}`; operand `{kind: input, path}` or `{kind: literal, value}`. Binary `eq ne gt gte lt lte contains`; unary `is_null is_not_null` (forbid `right`). Depth limit 64.
- Switch `value` is one operand; `cases` are `[{id, value}]`, id non-empty, unique, not `default`; value a JSON scalar, unique by strict type+value.
- Flow outlets: `if_else` exactly `true`/`false`; `switch_case` each case id plus `default`; everything else `out`; targets always `in`. One edge per outlet; several edges into one inlet are a legal rejoin.
- Unfinished seeds save: `if_else {execution:{inputs:[]}}` → diagnostic `missing_field …condition`; `switch_case {execution:{inputs:[],cases:[]}}` → `missing_field …value`; both refused at preflight (`invalid_shape`). Missing true/false outlet → `if_outlet_required` (draft + preflight).
- Execution: only the selected path runs (if: `yes please` → router, yes_agent; `no thanks` → router only; switch `a`/`b`/`zzz` → agent_a / agent_b / default straight to End). Rejoin needs no merge node; `first_present` in End resolves the branch that ran.
- Backend refuses only at preflight or run, not at save: duplicate case value, case id `default` (preflight); cross-type literal comparison and `contains` on a number pass preflight and fail at run. A switch whose case was deleted while its outlet edge remained **passes save and preflight** (runtime refuses at run: outlets must equal cases) — recorded for #356, handled in the editor by never leaving such an edge silently.

SEQ-NATIVE-BRANCH-01: new draft → Add If/Else (or Switch) → bind inputs → edit condition / value + cases → wire true/false (case/default) outlets and rejoin → Save (first save omits token) → reopen (load from store) → same document and controls → edit again → CAS save. Case rename/reorder keeps edges; deleting a wired case requires explicit confirmation and removes the case and exactly its outlet edge in one edit. Stale view / external replacement guards are the existing `editCurrent` / `document_revision` ones.

AC-BRANCH-01: palette adds `if_else` / `switch_case` with the measured seeds; real store saves and reads them back byte-equal; unfinished diagnostics are the measured ones.
AC-BRANCH-02: canvas draws one row per outlet aligned with its port (in-port left, outlets right), label at the edge's start; flow from true/false/case/default to any flow node; rejoin accepted; wrong outlet, occupied outlet, self, cycle refused with the original document returned; an edge leaving an undeclared outlet is still drawn and named, never hidden.
AC-BRANCH-03: condition editor builds the typed AST with explicit All/Any groups (nesting, short-circuit order is the list order), two-line comparison rows, operator menu filtered by the left side's declared type when the editor can prove it, unary null operators without a right side; nothing stored as a string expression. Unknown / unreadable condition shapes are shown read-only, preserved byte-for-byte, and only replaced on an explicit author action.
AC-BRANCH-04: switch editor edits the value operand, adds cases with fresh stable ids, renames values, reorders, removes (wired → confirm → case + its edge), Default fixed and undeletable; local problems for duplicate values / reserved id / cross-type literal / contains on a number / null with a binary operator, matching the backend's later refusal codes.
AC-BRANCH-05: downstream binding picker marks values only available on some paths (hollow `circle` icon); `first_present` remains the rejoin mechanism.
AC-BRANCH-06: actual page payload (create → configure → wire → Save) is consumed unchanged by the real store + installed runtime: saved, read back equal, preflight passes, and the real stream runs only the selected branch for each outcome with an offline SDK; reopen restores the same controls.
