## Diagnosis and design
HELLO showed full-backend reads reduced by unconditional head_tail even for 937/1120-byte results, plus partial artifact pages treated as full files. Current context pages already expose byte counts/eof/next_read. Historical wrappers say UNTRUSTED and optional task context, encouraging rejection of relevant evidence.

- Unchain ToolOutputManager: share size-first complete delivery for default/head_tail policies, preserving explicit artifact-only. Initial inline budget 16,000 UTF-8 bytes; account for final serialized projection metadata. Large canonical head_tail results use the existing immutable artifact locator/reader, not a new artifact. Do not apply generic offload to canonical context pages. Preserve source digests, read authority and error outcomes.
- context_content: introduce explicit v2 model page/error/descriptor presentation with historical-evidence terminology and fixed actionable notices. Strictly retain v1 decoding for old durable records; never alter v1 enum meanings. Unknown keys/versions fail closed. Page bytes/next offset describe actually delivered source, not backend buffered bytes. UTF-8 boundary handling and JSON escaping must fit the 12 KiB serialized cap; genuine binary remains recoverable.
- Historical compiler/checkpoint/recall and memory-tool presentation: replace host-owned evidence labels and prose, preserving literal record text and provenance, role separation and final-line JSON used for parsing. New and legacy markers are recognized where replay/dedup requires it; no storage authority is derived from presentation.
- Core/memory-tool guidance: explain default/index units, preview versus full coverage, use next_read, narrow relevant ranges, reuse currently available evidence, reread when content changed/missing or fresh validation is needed. Do not advertise absent tools or require every large result to be exhaustively read.
- PuPu: preserve existing UX/admission rules. Add fixed-wheel integration evidence/tests and this plan; modify consumers only if an actual closed consumer requires it. Runtime capability is determined by the imported code-backed manifest, never source path or Git SHA.
