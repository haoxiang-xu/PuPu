# PuPu 0.1.8 — Early Preview Release 🚀

A desktop AI client with a file-system chat explorer, memory, workspace context, and runtime management for both local and cloud models.

## What's New in 0.1.8

- 🎨 **Make PuPu yours — full theme customization** — a new theme editor lets you pick your own colors with a live preview, start from built-in presets, and import/export or reset themes. Colors now flow through a semantic palette, so the sidebar, surfaces, cards, and modals all stay consistent in both light and dark.
- ⌨️ **Talk to PuPu while it's working — in-run commands** — three new slash commands let you interject mid-response without stopping the run: `/fyi` adds info to the current task, `/btw` gets a quick answer without interrupting it, and `/queue` lines a message up to run after the current one finishes. Type `/` in the composer during streaming to see them.
- 🗂️ **Redesigned input & attach panel** — the composer got a rebuilt attach panel: cleaner toolkit / workspace / model controls, a tidier attachment chip row, and a compact queue pile that shows what's lined up next — all keyboard-reachable.
- 🧭 **New chat minimap** — the message-window minimap was rebuilt around evenly-spaced semantic markers, so navigating long conversations is smoother and stays responsive even during streaming.
- 💾 **Faster, more reliable chat storage** — conversations now live in a local database instead of being rewritten wholesale on every change. Large libraries stay snappy, and history is more durable.
- 📦 **Tools that just install — local runtime auto-setup** — MCP servers that need **Node (npx)** or **UV (uvx)** now get their runtime resolved and set up automatically. No more installs that silently fail because the environment wasn't ready.
- ⚠️ **Clear install errors** — when a toolkit install does fail, you now see the actual reason right on the toolkit card and detail panel, instead of a silent dead end.

### Fixes & Polish

- ⚡ **Smoother streaming** — reduced high-frequency re-renders while a response streams: persistence writes are throttled and deduplicated, the trace-chain timeline no longer rebuilds on every chunk, and the minimap runs mostly imperatively so it stays fluid.
- 🔗 **Trace chain finality** — fixed trace-chain completion ownership so tool/reasoning frames close out reliably, and fixed duplicate live text in no-tool turns (#155, #66).
- 🧭 **Smarter scrolling** — landing correction and scroll navigation for the message window, compensation for boot-window expansion and large streamed chunks, plus a bottom-viewport inset so the last message and the minimap aren't clipped.
- 🗂️ **Steadier Explorer** — collapsed folders no longer flash open during drag-and-drop, and collapsed folders unmount lazily to keep large trees light.
- 🎨 **Semantic theming under the hood** — shell, input, context menu, card, modal, and markdown think-block backgrounds are all routed through semantic tokens for cleaner light/dark parity.
- 🛠️ **Steadier runtime** — hardened the Unchain sidecar: safer interject setup and teardown, no catalog reads while Unchain is still starting, and fixes to the PuPu MCP store install / OAuth flows and build hooks.

## ⚠️ Known Limitations

This is still an **early preview**. Some features are incomplete and edge-case bugs may still exist. If you hit one, please open an issue.

## On the Horizon

Following the v0.1.5 convention, a short forward-looking note — roadmap previews, not release commitments. Scope and timing may change.

- **App-wide error toasts** — install errors now surface where they happen; the next step is a consistent, app-wide toast so any failure (not just toolkit installs) explains itself clearly and never fails silently.
- **Ultra Apps & Generative UI** — PuPu is exploring constrained, generative surfaces where the assistant can compose and adjust parts of the interface itself. The theme color picker is an early probe of that direction.
